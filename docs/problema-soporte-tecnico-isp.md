# Problema: Soporte Tecnico ISP

## 1. Contexto

Las organizaciones de servicios de Internet (ISP) gestionan el soporte tecnico de sus clientes mediante **canales informales como correos electronicos, llamadas telefonicas o mensajeria instantanea**, generando **desorganizacion, perdida de informacion y tiempos de respuesta prolongados**.

> **Fuente:** E2, cap. 1.1.1 (cita literal del documento).

## 2. Problema identificado

La gestion informal del soporte tecnico ISP presenta los siguientes problemas:

- **Desorganizacion:** las solicitudes se distribuyen entre multiples canales sin un registro centralizado.
- **Perdida de informacion:** no existe trazabilidad del historial de interacciones entre cliente y tecnico.
- **Tiempos de respuesta prolongados:** la falta de un sistema formal dificulta la priorizacion y asignacion eficiente de recursos.

## 3. Impacto

Sin un sistema formal, el ISP no puede:
- Medir tiempos de resolucion de incidencias.
- Garantizar que toda solicitud sea atendida.
- Generar metricas de desempeño del equipo de soporte.
- Escalar la operacion conforme crece la base de clientes.

## 4. Objetivo

Implementar un sistema distribuido de gestion de soporte tecnico que formalice el ciclo de vida de las solicitudes, desde la recepcion hasta la resolucion, permitiendo trazabilidad, disponibilidad y escalabilidad.

> **Fuente:** E3 — "fundamentaron el problema" (pilar obligatorio de E1).
